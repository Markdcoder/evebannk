# EveBank Starter (Next.js + Supabase + Flutterwave)

Deploy on Vercel. Add env vars from `.env.local.example`. Run Supabase SQL from `supabase/schema.sql`.

Routes:
- /           (sign-in + dashboard)
- /admin      (create virtual account for a UID)
- /api/me
- /api/bootstrap
- /api/admin/accounts/create
- /api/webhooks/flutterwave
